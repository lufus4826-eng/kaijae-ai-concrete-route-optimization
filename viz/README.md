# คู่มือหน้าจอแสดงผลแผนการจัดส่ง — ทีม KAIJAE AI (ไก่แจ้เอไอ)

หน้าจอแสดงผลในโฟลเดอร์นี้พัฒนาขึ้นเพื่อแก้ปัญหาหน้าจอเดิมของบริษัท (ที่แยกดูเป็นรายตารางและไม่เชื่อมโยงไทม์ไลน์) ให้ผู้ใช้งานหลายบทบาทในห่วงโซ่อุปทานเห็นข้อมูลสำคัญและตัดสินใจจากแผนเดียวกันได้ทันที

---

## 1. กลุ่มผู้ใช้งานที่ออกแบบมารองรับ (3 กลุ่มหลัก)

1. **ผู้บริหาร:**
   * เห็นภาพรวมการผ่านเกณฑ์ SLA รายวันและรวม 4 วันได้ทันที
   * ดูโครงสร้างรายได้ หักต้นทุนวัตถุดิบ ค่าขนส่ง ค่าโยกรถ ค่ารถรอ จนเหลือเป็นกำไรสุทธิ
   * ติดตามระยะทางรวมและการปล่อยก๊าซคาร์บอน (`CO₂`)
2. **เจ้าหน้าที่จัดคิวรถส่วนกลาง:**
   * ดูไทม์ไลน์ช่วงเวลาเทจริงของสายเทแต่ละหน้างาน (Gantt Timeline) เพื่อตรวจความต่อเนื่องและโอกาสเกิดรอยต่อคอนกรีต (Cold Joint)
   * ดูเวลาโหลด เวลาออกจากโรงงาน เวลาถึงหน้างาน และระยะห่างระหว่างคัน (`gap_min`) ของแต่ละเที่ยว
3. **ผู้จัดการโรงงานและพนักงานขับรถ (ผู้ใช้หน้างาน):**
   * ดูปริมาณเที่ยวโหลดของแต่ละโรงงาน (`P01`–`P08`) พร้อมหมายเหตุกำลังการผลิตจริง (`P05 = 2 ไลน์จริง`, `P07 = 3 ไลน์จริง`)
   * ดูตารางเดินรถรายคัน (ลำดับโรงงาน → หน้างาน และเวลาเริ่มโหลด) พร้อมแถบแจ้งเตือนเหตุการณ์จราจรและช่วงห้ามเข้าพื้นที่

## 3. วิธีเปิดใช้งาน

* ดับเบิลคลิกที่ไฟล์ `viz/dashboard.html` เพื่อเปิดผ่านเว็บเบราว์เซอร์ (Chrome / Edge / Safari / Firefox) ได้ทันที โดยไม่ต้องติดตั้งเซิร์ฟเวอร์หรือลงแพ็กเกจเสริม
* ตัวเลขผลลัพธ์ทั้ง 4 วันใน `viz/dashboard.html` อ้างอิงตรงจากไฟล์ผลประเมินจริงใน `out/day1` ถึง `out/day4` (`plan_result.json` และ `plan_loads.csv`)

---

## 4. จุดที่ดีกว่าหน้าจอเดิมของบริษัท

* **รวมมุมมองผู้บริหารและหน้างานในที่เดียว:** สลับบทบาทดูได้ทันทีโดยไม่ต้องเปิดข้ามหลายตาราง
* **เห็นความต่อเนื่องบนแกนเวลา:** แสดงช่วงเวลาเทจริงและช่องว่างระหว่างรถแต่ละคัน ช่วยตรวจจุดเสี่ยงขาดช่วงได้เร็วกว่าการไล่อ่านตารางข้อความ
* **เชื่อมตัวเลขปฏิบัติการเข้ากับกำไรและสิ่งแวดล้อม:** เห็นผลกระทบทั้งฝั่ง SLA, กำไรสุทธิ และปริมาณคาร์บอนไปพร้อมกัน
